Compuerta de calidad para historias de usuario

Antes de generar un escenario Gherkin, el insumo se evalúa contra una rúbrica acotada a una sola pregunta: si este criterio se viola, ¿todavía puedo derivar un Given–When–Then ejecutable?

Elige un ejemplo o escribe una historia, y evalúala para ver cómo se enruta.
